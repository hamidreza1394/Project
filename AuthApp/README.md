# پنل مدیریت مشتریان (CRM)

پنل فارسی و راست‌چین مدیریت مشتریان با Vite و Tailwind CSS

## اجرا
```bash
npm install
npm run dev
```

## ورود نمایشی
- نام کاربری: `admin`
- رمز عبور: `1234`

بعد از ورود، مستقیم وارد صفحه «تعریف مشتری» (گزینه اول سایدبار) می‌شوید.

## امکانات
- صفحه ورود حرفه‌ای + محافظ ورود (بدون ورود، دسترسی به پنل نیست)
- سایدبار زیبا (گزینه اول: تعریف مشتری) — جمع‌شونده در دسکتاپ و کشویی در موبایل
- فرم کامل تعریف مشتری حقیقی/حقوقی با اعتبارسنجی فارسی (کد ملی، موبایل، ایمیل...)
- نوار پیشرفت تکمیل فرم، انتخاب سطح مشتری (عادی تا VIP) و سقف اعتبار
- جدول مشتریان با جستجو، فیلتر سطح، ویرایش و حذف (مودال تأیید)
- ذخیره‌سازی خودکار در مرورگر (localStorage) + کارت‌های آمار زنده
